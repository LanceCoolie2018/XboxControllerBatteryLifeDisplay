# BatteryHUD Privacy Policy

**Last updated:** 2026-07-22  
**Product:** BatteryHUD  
**Publisher:** LanceCoolie2018 (GitHub) / listing publisher as set in Microsoft Partner Center

## Summary

BatteryHUD is a local desktop overlay that shows battery percentage for peripherals your operating system already exposes. It is designed for gaming and everyday use.

## Data stored on your device

- **Settings** (selected devices, window positions) are stored only on your device in the app’s local settings folder.
- **Log files** may be written on your device to help diagnose problems. Logs stay on your machine unless you choose to share them.

BatteryHUD does **not** run a background cloud account or analytics service.

## Bug reports

If you use **Report a bug**, the app can open your default web browser to a **GitHub Issue** form for the public project repository. That form may be pre-filled with:

- Your description of the problem  
- App version and basic OS / runtime information  
- A short **snippet of recent local log lines** (if available)

Submitting the issue is optional. You must be signed in to GitHub (or create an account) if GitHub requires it. Once submitted, the content is public on GitHub under that repository’s issue tracker and is subject to [GitHub’s privacy policy](https://docs.github.com/en/site-policy/privacy-policies/github-privacy-statement).

We do **not** embed secret API keys in the app for filing reports.

## Microsoft Store

If you install BatteryHUD from the Microsoft Store, purchase and licensing are handled by Microsoft under their terms. This policy covers the BatteryHUD application itself.

## Children

BatteryHUD is a general-audience utility and is not directed at children under 13.

## Contact

For privacy questions or bug reports related to BatteryHUD, open an issue on the project’s GitHub repository or use the in-app bug report button.

## Changes

We may update this policy when features change. The “Last updated” date at the top will change when we do.
